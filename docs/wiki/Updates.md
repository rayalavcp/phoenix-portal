# Updates

Phoenix updates itself from the project's
[GitHub Releases](https://github.com/rayalavcp/phoenix-portal/releases): it checks on start and
every 12 hours and shows **Update available** in the menu. Tap it, then **Update**; settings are
kept. To check now: remote admin › **Dashboard** › **Check for updates**.

Other ways to install a build:

- **By link, no USB**: remote admin › **Phoenix** › **Install apps on this Portal** › **Install
  from a link**:
  `https://github.com/rayalavcp/phoenix-portal/releases/latest/download/phoenix-portal.apk`
- **From a PC over USB**: the Windows installer (see [Install](Install.md)).

Only the newest three releases are kept on GitHub. Details:
[install/UPDATES.md](https://github.com/rayalavcp/phoenix-portal/blob/main/install/UPDATES.md).
