# Wiki source

These pages are the source of the project's GitHub wiki
(https://github.com/rayalavcp/phoenix-portal/wiki). They also read fine right here.

To publish them (from a computer with push access to the repository):

1. Once only: open the repository's **Wiki** tab on GitHub and create any first page, so GitHub
   creates the wiki.
2. Run `docs/wiki/publish-wiki.sh` from the repository root. It copies these pages into the
   wiki, turns `Page.md` links into wiki links and pushes.
